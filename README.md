# Дипломная работа «Облачное хранилище» по профессии Java-разработчик

## Описание работы
Реализован REST-сервис для хранения и управления файлами пользователя. Авторизация происходит через JWT. Интеграция с фронтендом без доработок.

## Используемые мною технологии
- Spring Boot 2.7.5
- PostgreSQL
- JWT (auth-token)
- Docker, Docker Compose
- JPA / Hibernate
- Maven
- Unit + Integration Tests (Mockito, Testcontainers)
