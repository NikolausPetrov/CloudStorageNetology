# Дипломная работа «Облачное хранилище» по профессии Java-разработчик

## Описание работы
Реализован REST-сервис для хранения и управления файлами пользователя. Авторизация происходит через JWT. Интеграция с фронтендом без доработок.

## Используемые мною технологии
- Spring Boot 2.7.5
- PostgreSQL
- JWT (auth-token)
- Docker, Docker Compose
- JPA / Hibernate
- Maven
- Unit + Integration Tests (Mockito, Testcontainers)

---

## Запуск сервиса

### Backend

```bash
docker-compose up --build
```

## Внесенные изменения по замечаниям преподавателя

### 1. Архитектурные улучшения
- **Сервисы теперь работают только с доменными объектами**: Убрал преобразования DTO из `StorageService`, теперь сервис возвращает `List<File>` вместо `List<FileResponse>`
- **Преобразования DTO вынесены на уровень контроллера**: В `StorageController` добавил преобразование `File` → `FileResponse` перед отправкой клиенту
- **Получение owner по токену вынесено в контроллер**: Теперь `JwtTokenUtils` используется только в контроллерах, сервисы принимают готовый `owner`

### 2. Добавлено логирование
- **StorageController**: Логирование всех операций с файлами (загрузка, удаление, переименование, скачивание)
- **AuthController**: Логирование попыток входа и выхода пользователей
- **StorageService**: Debug-логирование операций с БД
- **AuthService**: Логирование процесса аутентификации и генерации токенов
- **UserDetailsServiceImpl**: Логирование загрузки пользователей

### 3. Исправления тестов
- Обновлен `StorageServiceTest` под новую сигнатуру сервиса
- Убраны зависимости от `JwtTokenUtils` в тестах сервисов
- Исправлены типы возвращаемых значений в тестах
- Исправлены вызовы методов репозитория (`deleteByFilenameAndOwner` вместо `removeByFilenameAndOwner`)

### 4. Дополнительные улучшения
- Улучшена читаемость кода и структура проекта
